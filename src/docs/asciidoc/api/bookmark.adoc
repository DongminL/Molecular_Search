=== 즐겨찾기 (Info Bookmark)
`Token` 및 `분자 정보 ID`, `즐겨찾기 ID` 값을 통해 `분자 정보` 를 `즐겨찾기` `추가` 및 `삭제`, `리스트 요청` 등을 할 수 있습니다.

==== 에러 코드
분자정보 API 사용 시, 발생할 수 있는 에러
|====
| Http Status | 에러 이름 | 메시지 | 설명

| `NOT_FOUND(404)` | `NOT_FOUND_BOOKMARK` | "해당 즐겨찾기를 찾을 수 없습니다." | 존재하지 않는 즐겨찾기 정보 요청
| `CONFLICT(409)` | `ALREADY_EXIST_BOOKMARK` | "이미 즐겨찾기한 분자 정보입니다." | 중복된 즐겨찾기 정보 추가

|====
