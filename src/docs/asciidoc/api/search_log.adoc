=== 검색 기록 (Search Log)
`Token` 및 `검색 기록 ID` 값을 통해 유저의 `검색 기록` 을 `추가` 및 `삭제`, `리스트 요청` 등을 할 수 있습니다.

==== 에러 코드
분자정보 API 사용 시, 발생할 수 있는 에러
|====
| Http Status | 에러 이름 | 메시지 | 설명

| `NOT_FOUND(404)` | `NOT_FOUND_SEARCH_LOG` | "해당 검색 기록을 찾을 수 없습니다." | 존재하지 않는 검색 기록 요청

|====
