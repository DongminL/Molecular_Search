=== 분자 정보 (Chem Info)
`Keyword`, `SMILES`, `ID` 값을 통해 원하는 `분자 정보` 를 `요청` 및 `저장` 할 수 있습니다.

==== 에러 코드
분자정보 API 사용 시, 발생할 수 있는 에러
|====
| Http Status | 에러 이름 | 메시지 | 설명

| `NOT_FOUND(404)` | `NOT_FOUND_CHEM_INFO` | "해당 분자 정보를 찾을 수 없습니다." | 존재하지 않는 분자를 요청
| `CONFLICT(409)` | `ALREADY_EXIST_CHEM_INFO` | "이미 존재하는 분자 정보입니다." | 중복된 분자 데이터 저장
| `INTERNAL_SERVER_ERROR(500)` | `EXTERNAL_API_REQUEST_FAILED` | "알 수 없는 이유로 외부 API 요청이 실패하였습니다." | AWS나 인공지능 서버로 인한 오류

|====
