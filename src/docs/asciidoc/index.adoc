== 개요
`+CanChem+` 의 `AI를 활용한 분자 정보 검색 앱` 프로젝트의 API 문서입니다.

[NOTE]
====
해당 프로젝트 API문서는 개발 환경까지 노출되는 것을 권장합니다. +
====

[CAUTION]
====
운영 환경에 노출될 경우 보안 관련 문제가 발생할 수 있습니다.
====

=== 공통 요청 헤더
모든 요청에는 토큰 인증이 필요합니다. (로그인 제외)

|====
| 헤더명| 타입| 양식| 설명

| `Authorization` | `String`| Bearer YOUR_TOKEN | JWT (Your Token)

|====

=== 응답 상태 코드(Http Status)
응답 시, 다음과 같은 응답 상태를 제공합니다.

|====
| Http Status | 설명

| `OK(200)` | 요청에 따른 정상 응답
| `BAD_REQUEST(400)` | 요청값 누락 혹은 잘못된 기입
| `UNAUTHORIZED(401)` | 인증되지 않은 접근
| `FORBIDDEN(403)` | 권한에 맞지 않은 접근
| `NOT_FOUND(404)` | 없는 리소스 요청
| `CONFLICT(409)` | 중복된 데이터 저장
| `INTERNAL_SERVER_ERROR(500)` | 서버 내부 오류

|====

=== 에러 응답 형식
프로젝트는 다음과 같은 응답형식을 제공합니다.

==== 에러 응답

[source, json]
{
    "timestemp": "2024-04-28T22:12:52.756712100",   // 발생한 시간
    "path": "/api/logout",     // 요청받은 URL 경로
    "status": "401",    // HTTP Status
    "error": "TOKEN_EXPIRATION",    // 에러 코드
    "message": "토큰이 만료 되었습니다." // 에러 관련 메시지
}

==== 공통 에러 코드 (4XX, 5XX)

|====
| Http Status | 에러 이름 | 메시지 | 설명

| `BAD_REQUEST(400)` | `BAD_REQUEST` | "잘못된 요청입니다." | 요청값 누락 혹은 잘못된 형식 기입
| `UNAUTHORIZED(401)` | `TOKEN_EXPIRATION` | "토큰이 만료 되었습니다." | 만료된 토큰으로 접근
| `UNAUTHORIZED(401)` | `TOKEN_INVALIDITY` | "유효하지 않은 토큰입니다." | 잘못된 토큰과 함께 접근
| `UNAUTHORIZED(401)` | `REQUIRE_RELOGIN` | "재로그인이 필요합니다." | Refresh Token 만료 시 재로그인 요청
| `UNAUTHORIZED(401)` | `UNAUTHORIZED` | "유효한 인증을 해주세요." | 인증되지 않은 접근
| `FORBIDDEN(403)` | `FORBIDDEN` | "접근할 권한이 없습니다." | 접근 권한 부족
| `NOT_FOUND(404)` | `NOT_FOUND_PATH` | "잘못된 경로입니다." | 없는 경로로 요청
| `METHOD_NOT_ALLOWED(405)` | `METHOD_NOT_SUPPORTED` | "올바르지 않은 HTTP Method 요청입니다." | 잘못된 Method로 요청
| `INTERNAL_SERVER_ERROR(500)` | `SERVER_ERROR` | "알 수 없는 에러가 발생했습니다. 관리자에게 문의하세요." | 서버 내부 오류

|====
